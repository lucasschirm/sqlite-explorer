Hand a database to SQLite Explorer

This page is the sender: it embeds the explorer in an iframe, builds a SQLite database in memory (no server, no files), and hands it over with a single postMessage. The explorer opens it exactly like a dropped file.

Idle.

What gets sent 
targetWindow.postMessage(
  { type: "sqlite-explorer:handover", name: "demo.db", blob: dbBlob },
  explorerOrigin          // exact origin — never "*"
);

The explorer replies on the same channel: sqlite-explorer:handover:ack when the database was accepted, or sqlite-explorer:handover:nack with a reason when it was rejected (unknown origin, wrong shape, or not a SQLite file — the receiver checks the 16-byte header).
